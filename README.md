# AI-Powered IDS

AI-Powered Intrusion Detection System designed to detect and analyze suspicious network activity through an interactive web dashboard.

## Overview

This project combines Intrusion Detection, automated security-event analysis, and a web-based dashboard to help identify and understand suspicious network activity.

The system is designed to detect and analyze security events such as:

- Port Scanning
- Brute-Force Attacks
- Suspicious Login Activity
- Abnormal Network Traffic

## Running the Project

Clone the repository:

```bash
git clone https://github.com/mohamdcyber/AI-Powered-IDS.git
```

```bash
cd AI-Powered-IDS
```

Run the application:

```bash
python3 app_AI.py
```

Then open the local address provided by the application in your browser.
